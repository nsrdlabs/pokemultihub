# PokeMulti Hub 🎮

Navegador multitela leve e otimizado para jogar múltiplas instâncias simultâneas de **Poke Idle World** ou outros jogos idle de navegador no celular.

## 🚀 Recursos
- Alternância rápida entre 1, 2, 3 ou 4 telas simultâneas.
- Otimizado para consumir menos memória RAM e bateria.
- URL pré-configurada para o Poke Idle World (`https://poke.idleworld.online/login`).

## 📲 Como Baixar o App (APK)
1. Vá até a aba **Releases** no menu do repositório.
2. Baixe o arquivo `PokeMultiHub-debug.apk` da versão mais recente.
3. Instale o APK no seu dispositivo Android.
